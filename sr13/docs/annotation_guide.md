# Інструкція розмітки 50 речень (СР13, крок 1)

Розмітку виконує **людина** (методичка, п. 5). Файл — `data/gold.csv` (роздільник `;`, UTF-8). Для кожного
речення заповніть стовпчик `triples`; у `note` можна записати сумнів. Чернетку асистента
`data/gold_assistant_draft.csv` **не відкривайте** до завершення власної розмітки — вона потрібна лише для
контролю (`scripts/agree.py`).

## Що розмічаємо

Трійки (s, p, o), **прямо стверджені в цьому реченні**. Схема — та сама, що в ЛР13 (`../lab13/docs/extraction_schema.md`).

| p | s → o | Так | Ні |
|---|---|---|---|
| FEEDS | підстанція → підстанція | «№1 живить №10»; «№4 живиться від №10» (= 10 FEEDS 4); «ланцюг №7 → №5 → №12» (= 7→5, 5→12) | «зачіпає №4 на глибині 2»; «розташована на глибині 2 від №1» |
| LOCATED_IN | підстанція → область | «Підстанція №5 (Волинська область)»; «№9 у Закарпатській області» | «закарпатські підстанції: №9 …» (прикметник без слова «область») |
| MANAGES | диспетчер → підстанція | «диспетчер №4 відповідає за підстанцію №1» | «тимчасово події на №9 обробляє диспетчер №5»; «користується прогнозом» |
| CONNECTED_TO | споживач → підстанція | «споживач №5038, підключений до підстанції №1»; «комерційний №3310 … на №5» | — |
| HAS_METER | споживач → лічильник | «AMI-77410 комерційного споживача №3310» | перелік лічильників без власника |
| FORECASTS_FOR | модель → підстанція | «модель VAR №1 прогнозує для підстанцій №2 …»; «прогноз для підстанції №5 моделлю LSTM №2» | «диспетчер використовує прогноз моделі VAR №1» (немає підстанції) |
| INSTANCE_OF | модель → метод | «модель типу VAR»; «три моделі LSTM: №1, №2 і №3» | сама назва «LSTM №2» |

## Правила

1. **Обидва учасники названі в реченні.** Підмет із заголовка чи попереднього речення не враховується
   («Сама живить підстанції №2, №7» → `-`; «Підстанція живиться від №10, а та — від №1» → лише `1 FEEDS 10`).
2. Без висновків через ланцюг і без знань «з голови» (навіть якщо факт правдивий у графі ЛР9).
3. Номер без слова «підстанція» — підстанція, якщо з речення зрозуміло, що мова про підстанції; номер із 4 цифр —
   споживач; «№003» вимірювання — не сутність схеми.
4. Перелік («живить №10, №2 і №7») дає окрему трійку для кожного елемента.
5. Значення (кВт, %, дати), адреси та імена не розмічаються.

## Формат клітинки `triples`

Скорочено, через пробіл: `s p o`; кілька трійок — через `;`; речення без відношень — `-` (порожньо не можна).

```
1 FEEDS 10; 1 FEEDS 2; 1 LOCATED_IN Львівська
LSTM2 FORECASTS_FOR 11
3310 HAS_METER 77410; 3310 CONNECTED_TO 5
LSTM1 INSTANCE_OF LSTM
-
```

Підстанція / диспетчер / споживач — номер; лічильник — 5 цифр; модель — `LSTM2`, `VAR1`; область — назва
(`Львівська`, `Закарпатська`); метод — `ARIMA`, `VAR`, `LSTM`, `GRU`. Повні ID (`Substation_1`) теж приймаються.
Перевірка формату — `python scripts/evaluate.py` (покаже рядки, які не розібрано).
