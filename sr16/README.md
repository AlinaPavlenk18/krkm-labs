# СР16. Оцінювання рекомендаційної системи Hub «Прогнозування енергоспоживання»

Порівняння популярнісного, контентного й графового підходів на даних взаємодій ЛР16 (журнал переглядів фрагментів
знань, 72 користувачі, seed 42–46) з тим самим часовим розбиттям (train < 27.10.2026, test 27.10–06.11).

```powershell
python sr16/kms_reco_eval.py    
```

| Підхід | Що використовує |
|---|---|
| popularity | кількість train-переглядів розділу |
| content | TF-IDF слів і біграм розділу; профіль — зважене (згасання 14 днів) середнє переглянутих |
| graph | Personalized PageRank ЛР16 (граф «розділ – сутність – зв'язки КГ ЛР9») |

Метрики: precision@5, nDCG@10, coverage, novelty; для етичних ризиків — різноманіття (ILD за сутностями й документами,
кількість різних документів у top-10), упередження популярності (перцентиль популярності рекомендованого, Gini
експозиції) і MMR-переранжування. Холодний старт: нові користувачі з k = 0/1/3/5 першими переглядами (k = 0 —
популярність або профіль онбордингу) і 3 нові документи.
