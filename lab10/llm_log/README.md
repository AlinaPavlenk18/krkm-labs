Інструмент: Claude (claude.ai, середовище агентної роботи), сесія 23.10.2026.
Модель: `claude-opus-5-5` (ідентифікатор конфігурації сесії).
Параметри: інтерфейс claude.ai не дає задати temperature і seed — «н/д». Відтворюваність результатів забезпечено
тим, що всі вихідні дані LLM збережено у файлах (сирі версії — у цій папці), а детерміновані кроки мають seed = 42.

а всі числа для dense / hybrid / rerank отримано запуском на ПК студентки.

Конфіденційність: у LLM не передавалися фрагменти рівня restricted. Документи gen03 і kb15 (restricted) згенеровано
скриптом із синтетичних даних ЛР9 / складено за даними графа; запити до них (q39–q41) сформовано шаблоном у scripts/make_gold.py.

## Підказка P2 (генерація кандидатних запитів)

> Ти — розмітник для оцінювання пошуку в базі знань «Прогнозування енергоспоживання». За наданими документами
> рівнів public та internal склади запити користувачів (диспетчер, аналітик, студент) чотирьох типів:
> keyword (ключові слова з документа), paraphrase (те саме іншими словами, без ключових термінів), multihop
> (відповідь у двох місцях або документах), noanswer (правдоподібне питання, відповіді на яке в корпусі немає).
> Додай кілька запитів англійською. Для кожного запиту з відповіддю наведи докази: doc_id і ДОСЛІВНУ цитату
> (5–20 слів), що містить відповідь, з оцінкою 2 (пряма відповідь) або 1 (часткова). Не вигадуй цитат.
