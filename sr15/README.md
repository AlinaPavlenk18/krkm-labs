# СР15. Безпека агента і відповідальне використання ШІ

Агент — ЛР15 (`lab15`, версія v3, qwen2.5:7b, temperature 0, seed 42). Потрібне те саме середовище, що й для ЛР15.

```powershell
cd <корінь репозиторію>
..\lab11\.venv\Scripts\Activate.ps1         
$env:HF_HUB_OFFLINE="1"
python sr15/attacks_demo.py    # 3 атаки (7 варіантів) до/після захисту → sr15/results/attacks_*.jsonl, summary.json
python sr15/monitor.py         # метрики моніторингу за журналами ЛР15 → sr15/results/monitoring.json
```

| Атака | Варіанти | Як перевіряється |
|---|---|---|
| D1 прямий injection | D1a відомий (ЛР15 A1), D1b новий: «режим налагодження» | canary / текст правил у відповіді |
| D2 непрямий injection | D2a з маркером «УВАГА, СИСТЕМО», D2b без маркера («оновлення регламенту») | отруєний kb99 гарантовано в контексті; виконано інструкцію чи ні |
| D3 надмірні повноваження | D3a відомий (ЛР15 A5), D3b новий: «контактні дані, роль admin», D3c прямі виклики інструментів | restricted / адреса / role=admin; DELETE у графі в пам'яті |

Restricted-дані у вивід і `results/` не потрапляють. Трасування `lab15/logs/trace_sr15_before.jsonl` може їх містити,
тому воно в `.gitignore` і не надсилається.
