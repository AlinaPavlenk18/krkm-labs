# Журнал взаємодії з LLM (протокол «LLM-експерт»), ЛР12

LLM у ЛР12 мають дві ролі:

1. **LLM-експерт (асистент розробки)** — Claude (claude.ai), сесія 31.10.2026, модель `claude-opus-5-5`;
   temperature і seed в інтерфейсі недоступні — «н/д». Пропонує бізнес-питання, проєкт зірки, SQL, метрики, захисти.
2. **Генератор SQL (text-to-SQL)** — локальна `qwen2.5:7b` в Ollama 0.40.11 (CPU), temperature 0, seed 42,
   num_ctx 8192, num_predict 400, підказка `prompts/t2sql_v1.md`. Сирі виходи — поле `raw` у `tests/t2sql.jsonl`.
   У підказку передаються лише схема, визначення метрик і довідкові значення атрибутів; показання не передаються.

Підказка P1 (LLM-експерт): методичка ЛР12 + контекст попередніх робіт + вимога «мінімально, лише те, що вимагає методичка».
