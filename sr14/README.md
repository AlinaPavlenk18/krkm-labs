# СР14 · Метрики якості знань для KMS — «Прогнозування енергоспоживання»

8 метрик якості й використання знань (8 вимірів), розрахунок для сховища ЛР14, пороги для двох сценаріїв,
дашборд і тренд. Код ЛР14 (`../lab14/quality/common.py`, `conflicts.py`) використовується, а не дублюється.

| ID | Вимір | Формула | Чат | Аудит |
|---|---|---|---|---|
| M1 | повнота | 1 − відсутні обов'язкові зв'язки / усі слоти | ≥ 0,98 | 1,0 |
| M2 | узгодженість | 1 − величини з нерозв'язаними розбіжностями / усі величини | ≥ 0,95 | 1,0 |
| M3 | точність | нижня межа Вілсона 95 % для частки правильних у вибірці (n = 30) | ≥ 0,85 | ≥ 0,95 |
| M4 | актуальність | моделі, навчені ≤ 365 дн. тому / усі моделі | 1,0 | ≥ 0,6 |
| M5 | унікальність | 1 − секції з майже-дублікатом / усі секції | ≥ 0,97 | ≥ 0,99 |
| M6 | походження | записи з повним provenance / усі записи | ≥ 0,95 | 1,0 |
| M7 | використання | документи, процитовані RAG / доступні ролі analyst | ≥ 0,5 | ≥ 0,3 |
| M8 | довіра до відповідей | відповіді з валідним посиланням / відповіді, крім «Не знаю» | ≥ 0,9 | ≥ 0,98 |

Відкинуті метрики, запропоновані LLM: кількість переглядів документа і задоволеність користувачів (немає журналу
використання — не вимірюються автоматично); розмір графа й кількість документів (обсяг, а не якість); середня довжина
відповіді (не відображає якість).

